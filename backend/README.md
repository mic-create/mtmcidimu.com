# Mother Teresa Medical Centre (MTMC) — Backend API

Modern Node.js, Express, and PostgreSQL backend service for Mother Teresa Medical Centre.

## Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Authentication:** JSON Web Tokens (JWT) & bcrypt
- **Validation:** express-validator
